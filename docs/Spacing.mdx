## Conventions

| Contexte | Token |
| --- | --- |
| Interstice d'un groupe de tags/chips | `--folio-space-2` |
| Gap entre boutons | `--folio-space-3` |
| Padding vertical des lignes de liste | `--folio-space-4` |
| Gap entre colonnes d'une grille de stats | `--folio-space-7` |
| Padding horizontal de page (desktop) | `--folio-space-9` |
| Espacement entre sections | `--folio-space-11`–`--folio-space-13` |

## Grille

- Contenu centré, largeur max de lecture ~720px, mesures de texte ≤ 60ch.
- Breakpoint principal : `--folio-breakpoint-mobile` (768px). Un seul breakpoint — les layouts doivent être fluides entre les deux.
- Le radius est unique et vaut zéro : `--folio-radius-none`. Seule exception, `--folio-radius-full` (50%) pour les pastilles de statut et la marque du nav.
- Les coins crantés des CTA principaux ne sont pas un radius mais un `clip-path`, dimensionné par `--folio-pixel-notch` (10px) et `--folio-pixel-notch-inner` (5px). Voir `folio-button[variant="primary"][pixel]`.
