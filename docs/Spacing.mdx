# Spacing

**Grille 8 points.** Tout espacement, toute hauteur de composant et tout interligne est un multiple de 8. Le seul demi-pas est 4, réservé au padding interne des tags et badges — là où 8 casserait la hauteur de 24px.

Les tokens sont nommés par leur valeur en pixels. `--folio-space-24` vaut 24px, sans table de correspondance à mémoriser : le nom *est* la valeur.

## Hauteurs de contrôle

Les éléments interactifs ne se dimensionnent pas par leur padding vertical — ça dérive dès que la typo bouge. Ils prennent une hauteur fixe, en `box-sizing: border-box` pour qu'une bordure ne les pousse jamais hors grille.

| Token | Hauteur | Composants |
| --- | --- | --- |
| `--folio-control-sm` | 24px | Badge, Tag |
| `--folio-control-md` | 32px | Chip, ThemeToggle |
| `--folio-control-lg` | 40px | Button `card` et `ghost`, fermeture du Lightbox |
| `--folio-control-xl` | 48px | Button `primary` — le CTA |

## Conventions

| Contexte | Token |
| --- | --- |
| Interstice d'un groupe de tags/chips | `--folio-space-8` |
| Padding horizontal d'un bouton | `--folio-space-16` (CTA : `24`) |
| Padding vertical des lignes de liste | `--folio-space-16` |
| Gap entre colonnes d'une grille de stats | `--folio-space-32` |
| Padding horizontal de page (desktop) | `--folio-space-48` |
| Espacement entre sections | `--folio-space-64` à `--folio-space-128` |

## Grille et coins

- Contenu centré, largeur max de lecture ~720px, mesures de texte ≤ 60ch.
- Breakpoint principal : `--folio-breakpoint-mobile` (768px). Un seul breakpoint — les layouts sont fluides entre les deux.
- **Le radius vaut zéro** : `--folio-radius-none`. Seule exception, `--folio-radius-full` (50%) pour les pastilles de statut et la marque du nav. Le système n'a pas d'échelle d'arrondis, et c'est délibéré.
- Les coins crantés des CTA principaux ne sont pas un radius mais un `clip-path`, dimensionné par `--folio-pixel-notch` (8px) et `--folio-pixel-notch-inner` (4px) — eux aussi sur la grille.

## Élévation

Le système est plat : **aucune ombre portée**. L'élévation s'exprime par le niveau de surface, et par une bordure 1px quand l'élément flotte au-dessus du contenu.

| Token | Surface | Usage |
| --- | --- | --- |
| `--folio-elevation-0` | `color-bg` | La page |
| `--folio-elevation-1` | `color-bg-elevated` | Survols, panneaux surélevés, barres collantes |
| `--folio-elevation-2` | `color-bg-card` | Cartes, popovers, toasts, chrome du lightbox |

Les trois sont des alias des tokens de fond : ils suivent le thème sans redéclaration.
